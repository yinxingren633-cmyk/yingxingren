## 一、 核心概念与原理

### 1.1 什么是机场？
所谓“机场”，指批量提供网络代理节点订阅服务的供应商（因早期服务多基于图标为纸飞机的 Shadowsocks 软件而得名）。

**运行逻辑：**

[你的设备] ──(入口/加密)──> [国内中转服务器] ──(跨境专线/公网)──> [海外落地服务器] ──> [目标网站]

### 1.2 常用代理协议一览

| 协议类型 | 特点描述 | 适用场景 |
| :--- | :--- | :--- |
| **Shadowsocks (SS/SSR)** | 轻量高效，但在公网直连下较易被识别 | 适合 IPLC/IEPL 专线或中转环境 |
| **V2Ray (VMess/VLESS)** | 功能强大，生态完善，伪装性强 | 适合各种公网中转环境 |
| **Trojan** | 伪装成标准的 HTTPS 流量 | 隐蔽性极高 |
| **Hysteria 2 / TUIC** | 基于 QUIC/UDP，抗丢包能力极强 | 适合弱网、高丢包或晚高峰直连 |

## 四、 现实用户最容易踩的 10 大坑（重点防坑）

👇 点击下方标题可展开阅读详细忠告：

“年付跑路率 90%，月付才是真保命。”

痛点：很多新手为了省钱选择年付，结果不到三个月机场拔线跑路或服务质量严重缩水。

建议：坚决月付，最多季付。把折扣省下的钱当作购买“安全保障”的保险费。

真相：测速跑的是服务器极限，不代表实际网页加载速度；部分机场会对 Speedtest 节点做特殊优化。

关键指标：测速图无法反映 延迟抖动 (Jitter) 和 丢包率 (Packet Loss)，而后两者才是决定体验的关键。

痛点：买了机场发现 Netflix 只能看自制剧，Google 频繁弹验证码。

原因：落地 IP 被识别为数据中心（Data Center）IP。请优先选择标有 Native IP 或 Stream 解锁的节点。

提醒：在 10.0x 倍率节点下，下载 1GB 文件将直接扣除 10GB 套餐额度！

做法：看清节点名称后缀（如 [1.0x]），大文件下载切勿挂载高倍率专线。

真相：绝大多数人只用 HK/JP/SG/US 节点。大量的冷门节点多为廉价广播 IP，维护差。5 个优质专线节点远胜 100 个易断直连节点。

>[!CAUTION]
>OpenAI 和 Anthropic 对机房 IP 封控极严。切勿使用万人共用的热门节点登录重要 AI 账号，尽量选择住宅/家宽 IP。

安全原则：切勿通过不可信节点登录网银、加密货币钱包及敏感政企邮箱，且必须开启 二步验证 (2FA)。

最佳实践（主备双机场）：

主用：月付中转/专线（大流量、高速度）。

备用：按量付费不限时套餐（平时不扣量，主用瘫痪时作“救援梯”）。

经验：白天飞快不代表晚上好用。建议专门在晚上 21:00 - 22:30 晚高峰期测试 4K 视频加载与丢包情况。

规则：切勿在公开平台（微博、小红书等）宣传特定机场；严禁将订阅链接上传至开源平台，防止被封禁。
